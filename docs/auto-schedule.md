# Автосоздание игр по шаблону

Backend проверяет сохранённый шаблон при запуске и затем каждую минуту. Внешний cron не требуется. При включённом режиме недостающие игры добавляются в конец расписания; учитываются игры со статусом `scheduled`, которые ещё не завершились (завершение — через два часа после старта). Игра в 07:45 освобождает место в 09:45, новая появится при следующей проверке. Перенос карточки в архив после полуночи на это не влияет.

Переключатель в «Админ → Игры → Создать по шаблону» сразу сохраняет включение/выключение. Параметры шаблона сохраняются кнопкой «Сохранить настройки». Ручная кнопка «Запустить проверку сейчас» работает и при выключенной автоматике. Выключение не удаляет ранее созданные игры.

Все пути создания по шаблону (фоновый, ручной, внутренний endpoint) используют общую транзакционную блокировку PostgreSQL для защиты от дублей. Ошибки фоновой проверки записываются в лог; следующая проверка повторяет попытку. После простоя backend восполняет расписание при запуске. Режим `SMOKE=1` не запускает фоновый процесс.

Для этой версии нужен деплой backend и frontend. Дополнительные переменные и миграции не требуются.

Проверки: `cd backend && RSVP_TEST_DATABASE_URL=postgresql://postgres@localhost:5432/hockey_rsvp_checks npm test`. Интеграционный тест допускает только локальную тестовую БД с суффиксом `_checks` и использует отдельную временную схему.
