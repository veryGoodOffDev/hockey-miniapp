# Подсказки цвета команды (только frontend)

После формирования составов в списке «Буду» рядом с именем появляется маленький белый или синий квадрат. Цвет определяется сохранённым распределением A → белые, B → синие, как на экране составов. Если игрок не распределён, команды отсутствуют или данные противоречивы, значка нет. Порядок позиций и времени отметки не меняется. В списках OUT/не отметились цвет не отображается, даже если игрок остался в старом составе.

На карточках ближайших игр, где пользователь IN и включён в состав, в шапке под статусом игры появляется строка «Ты в команде —» с белым/синим квадратом. Проверяется актуальная отметка в ответе `/api/game`, чтобы не показывать подсказку игроку OUT из устаревшего состава.

Используется существующий `GET /api/game?game_id=...`. Дополнительная загрузка запускается после основного экрана и не блокирует карточки, кнопки RSVP или вход. До 12 ближайших игр IN, максимум два одновременных запроса, timeout каждого запроса 10 секунд. Отменённые/завершившиеся игры и OUT пропускаются. Ошибка загрузки просто скрывает дополнительную подсказку. Фонового polling нет. Данные загружаются заново при обновлении списка и возвращении на него из деталей/другой вкладки; при выходе запросы отменяются. Результаты другой игры/другого пользователя не используются.

Файлы: `teamColors.js`, `useGameTeamColors.js`, `TeamColorMark.jsx`, `RsvpStatusBlock.jsx`, `GameCard.jsx`, подключение в `TelegramApp.jsx`, стили в `styles.css`.

Деплой **только frontend** обычным способом (`cd webapp && npm ci && npm run build`, публикация `dist`). Backend, env-переменные и БД не меняются.

Проверки:

- `node --test webapp/src/teamColors.test.js webapp/src/rsvpPlayerOrder.test.js` — определение цвета в обоих форматах составов, OUT и отсутствие команд, неоднозначные данные, лимит/параллельность/отмена запросов, сортировка.
- `npm --prefix webapp run build`.
- Полное приложение в Chromium с имитацией Telegram и API: запуск, карточки доступны до ответа о цвете, белая/синяя подсказка, отсутствие составов, OUT, значки в списке, перенос игрока между командами и удаление составов при повторном открытии списка, ширина 320/390/430 px. Проверка также проводится на production-сборке через Vite preview. Реальные данные или настройки production не изменялись.
