# Настройки игры для администратора

Оба входа — шестерёнка на карточке игры и выбор игры в «Админ → Игры» — используют общий `webapp/src/admin/GameSheet.jsx`.

Редактор разделён на четыре вкладки:

- **Игра**: дата, время, арена, геоточка, важное объявление, подробности. Видео и действия отмены/восстановления/удаления раскрываются отдельно. Одна кнопка «Сохранить игру» сохраняет основные поля, тексты и ссылку на видео существующим PATCH `/api/games/:id`. Отправка видео в Telegram остаётся отдельным явным действием.
- **Игроки**: поиск по имени/номеру, счётчики статусов, изменение отметки с подтверждением и персональные ссылки на отметку. Ссылка раскрывается под игроком и не ломает ряд кнопок статуса.
- **Гости**: гости текущей игры и поиск по сохранённым гостям. Новый гость создаётся в отдельном окне. Основные поля сразу видны; навыки и заметки раскрываются отдельно. У существующего гостя доступны перевод в постоянные игроки по email и удаление с подтверждением.
- **Напоминания**: существующие напоминания, их изменение/удаление/сброс отправки и настройка послеигрового сообщения. Существующие API и правила доставки сохранены.

Переход между вкладками не сбрасывает введённые поля. Изменение гостя, отметки или настройки послеигрового сообщения не закрывает редактор: используется существующий `onChanged` с `action: "keep_open"`. Ошибка API при сохранении игры/гостя сохраняет окно и введённые данные; сообщение об успехе не показывается. Сохранение игры и успешное удаление игры закрывают редактор.

## Окна и мобильная вёрстка

- `GameSettingsDialog.jsx`: portal в `document.body`, непрозрачная поверхность, отдельные header/body/footer. Прокрутка только внутри body, фон не обрывается на длинной форме. Header, вкладки и footer не прокручиваются.
- Высота адаптируется к `visualViewport`, включая уменьшение доступной области при клавиатуре; предусмотрены safe-area и `prefers-reduced-motion`.
- Вложенные окна удерживают блокировку прокрутки страницы. Escape закрывает только верхнее окно; фокус возвращается на кнопку открытия, Tab удерживается внутри активного окна. Основной редактор получает `inert` при открытой форме гостя или карте.
- Карта выводится в portal над основным окном, не перекрывается новым диалогом.
- `GameSettings.css` использует отдельные классы `gsDialog*`, `gsSection*` и другие `gs*`. Старые общие `.sheet`, `.iconBtn`, `.guestFormGrid` больше не переопределяются встроенными стилями редактора игры. Общие карточки и редактор профиля игрока не меняются.
- `GameGuestEditor.jsx` содержит форму гостя, `GameParticipants.jsx` — список игроков и персональные ссылки.

## Деплой и проверка

Достаточно деплоя **frontend**. Backend, БД, env и зависимости не менялись.

```sh
npm --prefix webapp run build
NODE_PATH=/path/to/playwright/node_modules node webapp/tests/game-settings.browser.cjs http://localhost:4174/
```

Тест использует локальную production preview сборку и перехваченные API. Проверяет оба входа, вкладки и черновики, единое сохранение, ошибки и повтор сохранения, участников, статусы, ссылки, создание гостя, напоминания, отправку видео через макет, карту, вложенные окна и восстановление прокрутки. Проверяется отсутствие горизонтального переполнения на 320/390/430/800 px и форма гостя при высоте 420 px. Это браузерная имитация уменьшенной области экрана, не тест на физическом iPhone.

Во время разработки реальные сообщения в Telegram не отправляются и production БД не изменяется.
